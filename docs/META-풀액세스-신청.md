# Meta 앱 Full Access(옛 Standard Access) 신청 — 3단계

> 2026-09-07 정리. Meta는 2026-05-04부터 이름을 **"Marketing API Access Tier"**(Limited Access → Full Access)로 바꿨다. 옛 이름 "Ads Management Standard Access"와 같은 것.
> 우리 앱: **2252150572238444** (mk-dashboard 시스템 사용자 토큰 사용)

## 왜 필요한가 — 한도 차이 (시간당)
| | Limited(지금) | Full |
|---|---|---|
| 광고 관리 호출 | 300 + 40×활성광고수 | 100,000 + 40×활성광고수 |
| 인사이트 호출 | 600 + 400×활성광고수 | 190,000 + 400×활성광고수 |
| 시스템 사용자 | 1개 | 10개 |

활성 광고 ~190개면 지금은 시간당 약 8,000회 안쪽. 서버 수집(2단계)으로 하루 1,440회로 고정했으니 우리 혼자 쓸 때는 이미 여유. **판매용(여러 광고계정·여러 사용자)** 이면 Full Access가 필수.

## 자격 (자동 판정)
- 최근 15일 동안 Marketing API 호출 **500회 이상** → 2단계 수집이 하루 1,440회라 **2일이면 충족**
- 마지막 500회 오류율 **15% 미만** → 한도 초과 오류가 많이 섰던 날은 피해서, 수집이 하루 이상 조용히 돈 뒤 신청
- 화면 녹화(스크린캐스트) 업로드는 2026-05부터 **불필요**, 코드 변경도 없음

## 신청 절차 (사용자가 직접 — 5분)
1. https://developers.facebook.com/apps/2252150572238444 접속
2. 왼쪽 **앱 검수(App Review) → 권한 및 기능(Permissions and Features)**
3. 목록에서 **Marketing API Access Tier** (안 보이면 검색창에 "Marketing API") 찾기
4. 오른쪽 **+ 업그레이드(Upgrade)** 또는 **고급 액세스 요청** 클릭 → 요청 내용 확인 → 제출

## 판매용으로 갈 때 추가로 필요한 것 (지금은 아님)
다른 회사의 광고계정을 우리 앱으로 다루려면 **ads_read / ads_management 권한의 고급 액세스(Advanced Access)** 가 별도로 필요하다. 이건 정식 앱 검수:
- **비즈니스 인증** 필수 — 비즈니스 설정 → 보안 센터 → 비즈니스 인증 시작. 사업자등록증(회사명·주소가 비즈니스 설정과 일치), 회사 전화·이메일(도메인 메일 권장). 보통 1~3영업일
- 앱을 인증된 비즈니스에 연결 — 앱 설정 → 기본 설정 → 인증(Verification) → 시작
- 검수 제출물: 사용 설명 + **화면 녹화**(로그인 → 광고계정 선택 → 계층 조회 → 예산 변경까지 실제 동작), 테스트 계정 안내, 데이터 삭제 안내 URL(privacy.html 하단 항목으로 충당)
- 로그인 구조도 바뀌어야 함: 지금은 우리 시스템 사용자 토큰 1개 → 고객마다 **Facebook 로그인(OAuth)** 으로 자기 광고계정 권한을 주는 방식. 이건 별도 개발(반나절~1일)
