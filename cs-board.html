북마크 설치·사용법 (PC마다 한 번)
  1. 아래 버튼을 브라우저 북마크바에 끌어다 놓기 (북마크바가 안 보이면 ⌘+Shift+B / Ctrl+Shift+B)
    CS 상황판 보내기
  2. 카카오: 파트너센터 → 채널 → 채팅 화면에서 북마크 클릭
  3. 네이버: 네이버페이센터 → 고객관리 → 고객문의관리에서 답변여부 = 미답변으로 두고 북마크 클릭. 1분마다 '6개월 → 조회하기'를 자동으로 누르니 이 화면은 상황판 전용 탭으로 따로 열어두세요.
  4. 두 탭은 닫지 말고 켜 두기. 화면 왼쪽 아래에 "CS 상황판 전송 중"이 보이면 정상입니다.

숫자가 회색으로 바뀌고(2분 반 넘게 소식 없을 때) "갱신 없음"이 뜨면 그 탭이 닫혔거나 로그인이 풀린 것 → 다시 로그인하고 북마크를 한 번 더 누르세요. 읽기만 하고 카카오·네이버의 어떤 것도 바꾸지 않습니다.
