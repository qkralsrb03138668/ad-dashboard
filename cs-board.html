자동 실행 설치 (수집할 PC 한 대에만, 처음 한 번)
  1. 크롬에 Tampermonkey 설치 → Chrome에 추가
  2. 주소창에 chrome://extensions → Tampermonkey의 세부정보 → 사용자 스크립트 허용 켜기 (메뉴가 없으면 오른쪽 위 개발자 모드 켜기)
  3. CS 상황판 자동 실행 설치 클릭 → Tampermonkey 화면에서 설치
  4. 카카오 채팅 화면, 네이버페이센터 고객문의관리(답변여부 = 미답변)를 열면 처음 한 번씩 "이 PC에서 모을까요?" → 확인, 초대코드 입력
  5. 크롬 설정 → 시작 그룹 → 특정 페이지 열기에 두 주소 추가 → 크롬만 켜면 두 탭이 열리고 자동으로 돎
    카카오: https://business.kakao.com/space/10284378/channel/_tnulxj/chats
    네이버: https://admin.pay.naver.com/front/m/v2/customer/inquiry?fromUnanswered=true
  6. 크롬 설정 → 성능 → 항상 활성 상태로 유지할 사이트에 business.kakao.com, admin.pay.naver.com 추가 (안 보는 탭을 크롬이 재우지 않게)

화면 왼쪽 아래 "● CS 상황판 전송 중"이 보이면 정상. 탭이 여러 개면 한 탭만 수집하고 나머지는 "대기"로 표시돼요. 로그인이 풀리면 다시 로그인만 하면 자동으로 이어집니다. 끄려면 Tampermonkey 아이콘 → 이 스크립트 끄기.
